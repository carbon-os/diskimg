# diskimg v2

Pure-Go disk image manipulation. Attach, mount, edit, detach.
No root. No kernel. No VM. Works on Linux, macOS, Windows.

---

## End Usage

```go
package main

import (
    "fmt"
    "io"
    "log"
    "os"

    "github.com/carbon-os/diskimg"
)

func main() {
    // attach
    img, err := diskimg.Attach("debian.img")
    if err != nil {
        log.Fatal(err)
    }
    defer img.Detach("")

    // mount partition 1
    vol, err := img.Mount(1)
    if err != nil {
        log.Fatal(err)
    }
    defer vol.Unmount()

    // small file — simple write
    vol.WriteFile("etc/motd", []byte("welcome\n"), 0644)

    // remove a file
    vol.Remove("etc/issue")

    // make a directory
    vol.MkdirAll("opt/myapp", 0755)

    // large file — stream directly, never fully buffered
    f, err := vol.Create("opt/myapp/rootfs.tar")
    src, _ := os.Open("rootfs.tar")
    io.Copy(f, src)
    f.Close()

    // read back
    data, _ := vol.ReadFile("etc/os-release")
    fmt.Println(string(data))

    // list a directory
    entries, _ := vol.ReadDir("etc")
    for _, e := range entries {
        fmt.Println(e.Name())
    }

    // rename
    vol.Rename("etc/hostname.bak", "etc/hostname")

    // symlink
    vol.Symlink("/usr/bin/python3", "/usr/bin/python")

    // permissions + ownership
    vol.Chmod("etc/shadow", 0640)
    vol.Chown("etc/shadow", 0, 42) // root:shadow

    // stat a file
    info, _ := vol.Stat("etc/motd")
    fmt.Println(info.Size(), info.Mode())

    // open for streaming read
    r, _ := vol.Open("var/log/syslog")
    io.Copy(os.Stdout, r)
    r.Close()

    // open for streaming write with flags
    w, _ := vol.OpenFile("etc/hosts", os.O_WRONLY|os.O_TRUNC, 0644)
    fmt.Fprintln(w, "127.0.0.1 localhost")
    w.Close()

    // umount
    vol.Unmount()

    // detach — write to new file, original untouched
    img.Detach("out.img")
}
```

## Volume Methods

Full surface mirrors `os.*` exactly. Anyone who knows Go already knows this API.

```go
type Volume interface {

    // ── read ────────────────────────────────────────────────────────

    // ReadFile reads the named file and returns its contents.
    ReadFile(name string) ([]byte, error)

    // Open opens the named file for reading. Returns fs.File which
    // is also an io.Reader — use for large files to avoid buffering.
    Open(name string) (fs.File, error)

    // ReadDir reads the directory named by name, returns sorted entries.
    ReadDir(name string) ([]fs.DirEntry, error)

    // Stat returns FileInfo for the named file, following symlinks.
    Stat(name string) (fs.FileInfo, error)

    // Lstat returns FileInfo for the named file, not following symlinks.
    Lstat(name string) (fs.FileInfo, error)

    // Readlink returns the destination of the named symlink.
    Readlink(name string) (string, error)

    // ── write ───────────────────────────────────────────────────────

    // WriteFile writes data to the named file, creating or truncating it.
    WriteFile(name string, data []byte, perm fs.FileMode) error

    // Create creates or truncates the named file, returns handle for streaming.
    Create(name string) (*File, error)

    // OpenFile is the general open call, mirroring os.OpenFile exactly.
    // Flags: os.O_RDONLY, os.O_WRONLY, os.O_RDWR, os.O_CREATE,
    //        os.O_TRUNC, os.O_APPEND, os.O_EXCL
    OpenFile(name string, flag int, perm fs.FileMode) (*File, error)

    // Mkdir creates a single directory.
    Mkdir(name string, perm fs.FileMode) error

    // MkdirAll creates a directory and all parents as needed.
    MkdirAll(path string, perm fs.FileMode) error

    // Remove removes a file or empty directory.
    Remove(name string) error

    // RemoveAll removes a path and all children, like rm -rf.
    RemoveAll(path string) error

    // Rename renames (moves) oldpath to newpath.
    Rename(oldpath, newpath string) error

    // Symlink creates a symbolic link newname → oldname.
    Symlink(oldname, newname string) error

    // Link creates a hard link newname → oldname.
    Link(oldname, newname string) error

    // ── metadata ────────────────────────────────────────────────────

    // Chmod changes the mode of the named file.
    Chmod(name string, mode fs.FileMode) error

    // Chown changes the uid and gid of the named file.
    Chown(name string, uid, gid int) error

    // Chtimes changes the access and modification times of the named file.
    Chtimes(name string, atime, mtime time.Time) error

    // ── volume info ─────────────────────────────────────────────────

    // Stat returns overall volume info — size, free space, block size.
    StatFS() (VolumeInfo, error)

    // Type returns the filesystem type: ext4, fat32, etc.
    Type() fstype.Type

    // ── lifecycle ───────────────────────────────────────────────────

    // Unmount flushes journal, syncs dirty blocks, releases volume.
    Unmount() error
}

// VolumeInfo mirrors syscall.Statfs_t but cross-platform.
type VolumeInfo struct {
    TotalBytes int64
    FreeBytes  int64
    UsedBytes  int64
    BlockSize  int64
    Inodes     int64
    InodesFree int64
}
```

## How It Works

### Layer 1 — Container (diskimg)

```
Attach("debian.img")
  │
  ├── open file handle
  ├── parse GPT or MBR partition table
  └── build region map
        ├── RegionBoot       0x0000 → 0x0200     (MBR + GRUB + GPT header)
        ├── RegionPartition  0x0200 → 0xA00000   (partition 1)
        ├── RegionGap        0xA00000 → 0xA00200 (between partitions)
        ├── RegionPartition  0xA00200 → ...      (partition 2)
        └── RegionBackup     ...  → end          (GPT backup header)
```

No data is read into memory. The region map is just math on offsets.

```go
type Image struct {
    f          *os.File
    size       int64
    partitions []*Partition
    regions    []*Region       // ordered byte ranges
    mounts     map[int]Volume  // active mounts
}

type Region struct {
    Kind           RegionKind
    Start          int64       // byte offset, inclusive
    End            int64       // byte offset, exclusive
    PartitionIndex int         // 1-based, only when Kind == RegionPartition
}

type RegionKind int

const (
    RegionBoot      RegionKind = iota  // MBR + GRUB + GPT header
    RegionPartition                    // filesystem lives here
    RegionGap                          // between partitions
    RegionBackup                       // GPT backup header
)
```

---

### Layer 2 — Mount

```
img.Mount(1)
  │
  ├── look up partition 1 in region map → start, size
  ├── build SectionReader over that byte range
  ├── detect filesystem (ext4 / FAT32)
  └── return Volume backed by that SectionReader
```

`SectionReader` is the block device equivalent — zero memory, just arithmetic:

```go
sr := io.NewSectionReader(img.f, region.Start, region.Size())
// reads on sr translate directly to seeks on the underlying file
// nothing is loaded into memory
```

---

### Layer 3 — Volume (ext4)

```
vol.WriteFile("etc/motd", data, 0644)
  │
  ├── walk path → find parent dir inode
  ├── allocate new inode
  ├── allocate blocks for data
  ├── write data blocks via SectionReader
  ├── update extent tree
  ├── update parent dir entry
  └── mark inode dirty (journaled)

vol.Create("opt/myapp/rootfs.tar") → *File
io.Copy(f, src)
  │
  └── allocates + writes blocks in chunks as data streams in
      never buffers the full file
      20GB file = ~32KB buffer at any point
```

Only touched blocks are read or written. For a 20GB partition
changing one small file — memory usage is kilobytes.

---

### Layer 4 — Detach

```
img.Detach("out.img")
  │
  ├── create out.img, pre-allocate to source size
  └── walk region map in order
        ├── RegionBoot       → copyRange verbatim  (GRUB untouched)
        ├── RegionPartition 1→ stream from vol     (modified ext4)
        ├── RegionGap        → copyRange verbatim
        ├── RegionPartition 2→ copyRange verbatim  (untouched)
        └── RegionBackup     → copyRange verbatim  (GPT backup untouched)
```

The output image boots because:

```
RegionBoot copied verbatim      → MBR + GRUB + GPT header valid
RegionBackup copied verbatim    → GPT redundancy valid
Partition offsets never moved   → bootloader block refs valid
Partition sizes never changed   → GPT still describes reality
Filesystem contents changed     → ext4 internally consistent
```

## Package Layout

```
diskimg/
  attach.go       — Attach, Image
  mount.go        — Mount
  detach.go       — Detach, copyRange
  region.go       — Region, RegionKind, buildRegions

  fs/
    volume.go     — Volume interface, VolumeInfo, File
    fstype/
      detect.go   — magic byte detection

  ext4/
    open.go       — superblock, block groups
    read.go       — ReadFile, Open, ReadDir, Stat, Lstat, Readlink
    write.go      — WriteFile, Create, OpenFile, Remove, RemoveAll
                    Rename, Symlink, Link
    meta.go       — Chmod, Chown, Chtimes
    alloc.go      — inode + block allocator
    journal.go    — journaling, checksums
    flush.go      — Unmount, sync dirty blocks

  fat32/
    open.go
    read.go
    write.go
    meta.go
    flush.go

  partition/
    partition.go
    gpt/gpt.go
    mbr/mbr.go
```

## Memory Profile

| operation              | memory       |
|------------------------|--------------|
| Attach                 | ~few KB      |
| Mount                  | ~few KB      |
| ReadFile (small)       | file size    |
| Open + stream (large)  | ~32KB buffer |
| WriteFile (small)      | file size    |
| Create + stream (large)| ~32KB buffer |
| Detach                 | ~32KB buffer |
| 20GB partition         | never in RAM |
